## Project Title

Pizza Sales Analysis Dashboard

## Brief One-Line Summary

Analyzed pizza sales data using SQL, Excel, and Power BI to identify sales trends, top-performing products, customer ordering patterns, and overall business performance.

## Overview

In this project, I analyzed pizza sales data for the year 2015. My main goal was to understand overall sales performance, identify popular pizza categories and sizes, and discover customer ordering patterns.

I used SQL to perform data analysis, Excel for data preparation and exploration, and Power BI to create an interactive dashboard.

## Problem Statement

The business wanted to understand its pizza sales performance and identify opportunities to improve revenue.

I focused on finding answers to the following business questions:

- What is the total revenue and number of orders?
- Which pizza category generates the highest revenue?
- Which pizza size is most popular?
- Which days and months have the highest orders?
- Which pizzas are the best and worst sellers?
- What are the main sales trends throughout the year?

## Dataset

The dataset contains pizza sales transaction records for the year 2015.

**Dataset Information:**

| Description | Details |
|---|---|
| Dataset Name | pizza_sales.csv |
| Total Records | 48,620 |
| Total Columns | 11 |
| Total Orders | 21,350 |
| Total Pizza Names | 32 |
| Pizza Categories | 4 |
| Pizza Sizes | 5 |
| Time Period | January – December 2015 |
| Missing Values | 0 |
| Duplicate Rows | 0 |
| File Format | CSV |

**Dataset Columns:**

| Column Name | Description |
|---|---|
| pizza_id | Unique pizza transaction ID |
| order_id | Unique order ID |
| pizza_name_id | Pizza identification code |
| quantity | Number of pizzas sold |
| order_date | Date of the order |
| unit_price | Price of one pizza |
| total_price | Total price of the pizza item |
| pizza_size | Size of the pizza |
| pizza_category | Category of the pizza |
| pizza_ingredients | Ingredients used in the pizza |
| pizza_name | Name of the pizza |

## Key Insights

### Overall Sales Performance

- **Total Revenue:** $817.86K
- **Total Orders:** 21.35K
- **Total Pizzas Sold:** 49.57K
- **Average Pizzas Per Order:** 2.32
- **Average Order Value:** $38.31

### Day-wise Sales Analysis

- Friday recorded the highest number of orders (3,538).
- Sunday recorded the lowest number of orders (2,624).
- Thursday and Saturday also showed strong sales performance.

### Month-wise Sales Analysis

- July was the best-performing month, with 1,935 orders.
- October recorded the lowest number of orders, with 1,646.
- May and January also performed well.

### Pizza Category Analysis

- Classic Pizza generated the highest revenue, contributing 26.91%.
- Supreme contributed 25.46%.
- Chicken contributed 23.96%.
- Veggie contributed 23.68%.

### Pizza Size Analysis

- Large size contributed the highest revenue share at approximately 45.89%.
- Medium size contributed 30.49%.
- Small size contributed 21.77%.
- XL size contributed 1.72%.
- XXL size contributed 0.12%.

### Best-Selling Pizzas

- The Thai Chicken Pizza generated the highest revenue ($43.43K).
- The Classic Deluxe Pizza sold the highest quantity (2,453 pizzas).
- The Classic Deluxe Pizza also recorded the highest number of orders (2,329).

### Worst-Selling Pizzas

- The Brie Carre Pizza generated the lowest revenue ($11.59K).
- The Brie Carre Pizza also had the lowest quantity sold (490 pizzas).
- The Brie Carre Pizza recorded the lowest number of orders (480).

## Dashboard / Model / Output

I developed an interactive Pizza Sales Analysis Dashboard using Power BI to present the business performance in a clear and visual format.

The dashboard includes:

- Total Revenue, Total Orders, and Total Pizzas Sold KPIs.
- Average Order Value and Average Pizzas Per Order.
- Daily and Monthly Order Trends.
- Revenue Contribution by Pizza Category.
- Revenue Contribution by Pizza Size.
- Pizza Sales by Category.
- Top 5 Best-Selling Pizzas.
- Bottom 5 Worst-Selling Pizzas.
- Date and Pizza Category Filters.

The dashboard helps users explore sales performance and compare different business metrics.
